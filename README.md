# Symptly

A SwiftUI iOS app for tracking symptoms and wellness, built so health data stays on the device.

Built in Swift as an Xcode project (`Symptly`), with unit and UI test targets, a wellness model trained in `train_wellness_model.py`, and marketing and support pages under `Marketing/` and `docs/`.

## Build

Open `Symptly.xcodeproj` in Xcode and run the `Symptly` scheme on a simulator or device.
