## Image Selection Rules

### Do
- **Match the image to the post topic.** Talking about ML? Use `insights_score.png`. Talking about onboarding? Use an onboarding screenshot.
- **Alternate between raw and polished.** Raw simulator screenshots feel authentic for build-in-public. Polished App Store screenshots feel professional for product announcements.
- **Crop or annotate when helpful.** Circle a specific detail you're discussing. Add an arrow to the element you redesigned.
- **Use before/after pairs.** If you have an old screenshot saved, pair it with the current version to show evolution.

### Don't
- **Don't reuse the same image within 7 days.** Check `POST_CATALOG.md` image column.
- **Don't use images on every post.** Mix text-only posts (feel spontaneous) with image posts (feel intentional). Aim for ~60% of posts having images.
- **Don't use polished App Store screenshots for "raw/honest" posts.** Mismatch kills authenticity.
- **Don't show the same screen 3x in a week.** Rotate across all screens even if you're focused on one feature.
