# Hashtag Strategy

> Which tags to use, how many, and when. Less is more on Twitter — this isn't Instagram.

---

## The Rules

1. **Max 2 hashtags per tweet.** More than that looks spammy and tanks reach on X. Zero hashtags is often better than three.
2. **Never put hashtags in the middle of a sentence.** If you use them, put them at the end.
3. **Don't hashtag every post.** Maybe 40-50% of posts. The casual ones should have none.
4. **Threads: hashtag only in tweet 1.** Rest of the thread stays clean.
5. **Replies: never use hashtags.** Makes you look like a bot instantly.

---

## Primary Hashtags (Use Often)

| Hashtag | When to Use | Audience It Reaches |
|---------|-----------|-------------------|
| #buildinpublic | Any post about shipping, progress, metrics | Indie hackers, founders, builders |
| #indiehacker | Feature updates, revenue/download numbers, solo dev life | Same as above, slightly different crowd |
| #iosdev | SwiftUI, Swift, Xcode, Apple framework posts | iOS developer community |
| #healthtech | Health data, privacy, clinical features, health industry takes | Digital health professionals and enthusiasts |

---

## Secondary Hashtags (Use Sometimes)

| Hashtag | When to Use | Notes |
|---------|-----------|-------|
| #swiftui | Specifically about SwiftUI code or design decisions | Niche but highly engaged community |
| #vibecoding | Posts about building with AI tools | Trending in 2026, may fade — monitor |
| #solofounder | Personal journey, building alone, founder life | Emotional connection hashtag |
| #machinelearning | ML architecture, on-device inference, model design | Reaches ML community on Twitter |
| #chronicillness | Posts about understanding chronic conditions (not marketing posts) | Use with care and empathy — never attach to promotional content |
| #applehealth | HealthKit integration, Apple Health ecosystem | Small but targeted |
| #coreml | On-device ML, CoreML implementation details | Very niche, very engaged |
| #privacyfirst | Posts about data privacy, on-device processing | Resonates with privacy-conscious users |

---

## Hashtags to Avoid

| Hashtag | Why |
|---------|-----|
| #startup | Too broad, attracts hustle-culture accounts and spam follows |
| #entrepreneur | Same as above. Attracts bots and motivational quote accounts |
| #AI | Way too broad. Your post gets lost in a sea of noise |
| #health | Too generic, reaches nobody specific |
| #app | Meaningless volume |
| #coding | Broad, low-quality engagement |
| #mobileapp | Attracts dev shops looking for clients, not real followers |
| #motivation | Absolutely not |

## Hashtag Pairing Guide

Pick max 2 from compatible pairs:

| Post Type | Good Pair | Example |
|-----------|----------|---------|
| Shipped a feature | #buildinpublic + #iosdev | "just shipped the symptom logging flow #buildinpublic #iosdev" |
| ML deep dive | #machinelearning + #coreml | "on-device bayesian inference for health data #machinelearning #coreml" |
| Health empathy post | #chronicillness only (or none) | Keep it genuine. One tag max. |
| Vibe coding / AI tools | #vibecoding + #buildinpublic | "claude wrote my time series analyzer in 20 minutes #vibecoding #buildinpublic" |
| Founder journey | #solofounder + #indiehacker | "month 3 of building alone #solofounder #indiehacker" |
| Privacy take | #healthtech + #privacyfirst | "your health data should never leave your phone #healthtech #privacyfirst" |
| Thread (tweet 1 only) | #buildinpublic + one relevant | One topical tag in the hook tweet, nothing in the rest |

## X Communities (More Important Than Hashtags)

For accounts under 5k followers, posting to X Communities gives more distribution than any hashtag. Prioritize these:

| Community | Post Type |
|-----------|----------|
| Build In Public | Shipping updates, metrics, journey posts |
| Indie Hackers | Product launches, revenue, tools |
| iOS Development | SwiftUI, Swift, technical content |
| Health & Wellness | Health insights (not product marketing) |
| AI Builders | AI tool usage, ML implementation |

**Post to communities in Phase 1-3.** After 5k followers your regular feed has enough distribution.
