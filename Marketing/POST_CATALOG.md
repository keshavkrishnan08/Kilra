## Format Tags

Use these consistently for filtering and analysis:

| Tag | Meaning |
|-----|---------|
| `tweet` | Single standalone post |
| `thread` | Multi-tweet thread (log first tweet, note "thread: X tweets") |
| `poll` | Poll post |
| `QT` | Quote tweet of someone else's post |
| `reply` | Reply to another account (log in COMMENTS_PLAYBOOK.md instead unless it's a notable reply) |
| `image` | Post with attached screenshot/mockup |
| `video` | Post with video/screen recording |

## Content Duplication Check

Before posting, Cowork should scan the last 14 days of this catalog and verify:
1. No post covers the same specific topic within 7 days
2. No hook is reused within 14 days
3. No screenshot/image is reused within 7 days
4. Post format varies: no more than 3 of the same format in a row
